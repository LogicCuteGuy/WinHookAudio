# Spec — v10.5 Virtual Cable (8× Stereo + RingBuffer + IOCTL)

## Problem Statement
From the user's perspective: `v10.4` `WHAA` `14` is green (`a6b8848`, `7/7` `ctest` PASS, `stream_verified:false`) but has no `Virtual Cable` — `SLOT_VIRTUAL` `2` + `virtualBuffer 256` + `IsLoopbackValid` + `PanelFilter::Virtual` + `SetInputLoopback` `VIRTUAL` only already exist, `MasterHolder` loopback stub `memcpy` `OUT→IN` already proves `VRChat → Virtual1 → DAW → Virtual3 LOOP → VRCT` `~5.4ms` without `sys`, `WHAControlPanelUI` `Loop` checkbox `VIRTUAL` only already done, but no `WinHookAudio.sys` `8× Stereo` `16ch` `Virtual 1..8 L/R` `64KB RingBuffer` `DeviceIoControl IOCTL_WHA_READ/WRITE/SET_LOOPBACK` `WDK` `PortCls` `WaveRT` `MSVAD` `Root\WinHookAudio` `WinHookAudio.inf/.cat`, no `MasterHolder` `DeviceIoControl` wiring, no `GENERAL` `Virtual Cables: [8 v] 8× Stereo Name[WinHookAudio Virtual]` + `Alternative mode 1× 64ch`. No `Installer` in this spec.

## Solution
From the user's perspective: `Virtual Cable` `WinHookAudio.sys` `8× Stereo` `16ch` `Virtual 1..8 L/R` `64KB RingBuffer` `DeviceIoControl IOCTL_WHA_READ/WRITE/SET_LOOPBACK` `WDK` `PortCls` `WaveRT` `MSVAD` `Root\WinHookAudio` `WinHookAudio.inf/.cat`, `MasterHolder::doTick()` does `Virtual: DeviceIoControl(IOCTL_WHA_READ) → SHM In` + `SHM Out → DeviceIoControl(IOCTL_WHA_WRITE)` + `Loopback: if Master OUT loopback=v → copy to Master IN next tick` + `SET_LOOPBACK` for `Virtual3` `Ring` → `VRCT`, one `MMCSS Pro Audio` thread, `RingBuffer` as `std::array<float,64*1024>` per `Virtual` `1..8`, `GENERAL` `Virtual Cables: [8 v] 8× Stereo Name[WinHookAudio Virtual]` + `Alternative mode 1× 64ch` in first slice, `WDK 11 22621` `PortCls` `WaveRT` `MSVAD` sample vendored under `third_party/wdk/` like `ASIO`/`ImGui`/`libvorbis`, `.gitignore` payload, `README` fetch step, stub `WinHookAudio.sys` as `memcpy` fallback for offline `ctest` (`stream_verified:false`), `WinHookAudio.sys` `WDK` `PortCls` `WaveRT` + `WinHookAudio.inf/.cat` + `testsigning` + `ADMIN=True` follow as `18` with `WDK` `22621` + `Bitwig` runtime gate.

## User Stories
1. As a streamer, I want `Virtual Cable` `WinHookAudio.sys` `8× Stereo` `16ch` `Virtual 1..8 L/R` `64KB RingBuffer` `DeviceIoControl IOCTL_WHA_READ/WRITE/SET_LOOPBACK` `WDK` `PortCls` `WaveRT` `MSVAD` `Root\WinHookAudio` `WinHookAudio.inf/.cat`, so that `Chrome`/`Discord`/`OBS`/`VRChat` each have dedicated `Stereo` `Virtual` `1..8`.
2. As a streamer, I want `INPUTS Tab VIRTUAL Virtual1 L = VRChat Out ↔ Windows Sound VRChat Output → WinHookAudio Virtual 1` + `OBS/VRCT captures Virtual 3`, so that `VRChat` `Output` → `WinHookAudio Virtual 1` + `VRCT` captures `Virtual 3`.
3. As a streamer, I want `Loopback flow: VRChat → Virtual1 Ring → Worker IOCTL → Master SHM In02 → DAW Track → Master SHM Out03 LOOP=v → Worker memcpy → Master SHM In03 (loopback) + Virtual3 Ring → VRCT loop ~5.4ms (2×128) without extra DAW track`, so that `VRChat → Virtual1 → DAW → Virtual3 LOOP → VRCT` `~5.4ms` without extra `DAW` track.
4. As a streamer, I want `Worker` `MasterHolder::doTick()` `Virtual: DeviceIoControl(IOCTL_WHA_READ) → SHM In` + `SHM Out → DeviceIoControl(IOCTL_WHA_WRITE)` + `Loopback: if Master OUT loopback=v → copy to Master IN next tick` + `SET_LOOPBACK` for `Virtual3` `Ring` → `VRCT`, so that `Virtual` `Read`/`Write` + `Loopback` share `Master_Tick` `SetEvent`.
5. As a template keeper, I want `GENERAL` `Virtual Cables: [8 v] 8× Stereo Name[WinHookAudio Virtual]` + `Alternative mode in GENERAL: 1× 64ch single device`, so that `8× Stereo` `16ch` `Virtual 1..8 L/R` `64KB` `RingBuffer` + `GENERAL` `8` `Combo` in same slice.
6. As a performer, I want `Master Clock` `2.7ms@128/48k` `ONE tick for all 512ch` with `Worker` `MMCSS Pro Audio` `WaitForSingleObject(Master_Tick)`, so that `Virtual 256` `Per-Thing` `FIFO` is `~2` ticks `128/48k`.
7. As a tester, I want offline `ctest` green without `ADMIN`/`WDK`/`sys`/`DAW`, `stream_verified:false`, `8× Stereo` `64KB` `RingBuffer` + `IOCTL_WHA_READ/WRITE/SET_LOOPBACK` stub without `sys` install, `MasterHolder` `DeviceIoControl` stub as `memcpy` fallback.
8. As a developer, I want `WDK 11 22621` `PortCls` `WaveRT` `MSVAD` sample vendored under `third_party/wdk/` like `ASIO`/`ImGui`/`libvorbis`, `.gitignore` payload, `README` fetch step, stub `WinHookAudio.sys` as `memcpy` fallback for offline `ctest`.
