# WinHookAudio

Implement production components in C/C++.
The DAW hosts this project's ASIO driver DLL.
The DAW owns mixing, effects, and routing.
The driver exposes KS devices, virtual cables, ASIO bridges,
and LAN audio through a native C++ configuration panel.

Read docs/architecture.md and docs/implementation-plan.md.
The HTML prototype is a design reference, not production code.
Do not claim audio functionality without runtime verification.
