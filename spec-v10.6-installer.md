# Spec — v10.6 Installer (5 CLSIDs + Inno Setup + Firewall + Driver)

## Problem Statement
From the user's perspective: `v10.5` `Virtual Cable` is green (`d79934f`, `8/8` `ctest` PASS, `stream_verified:false`) but has no `Installer` — no `5 CLSIDs` `WinHookAudio Master` + `Bridge1..4` `HKLM\SOFTWARE\ASIO` `WinHookAudio.reg`, no `Inno Setup` `WinHookAudio.iss` `6.x` `iscc`, no `WinHookAudio.sys` `8× Stereo` `WDK` `PortCls` `WaveRT` `WinHookAudio.inf/.cat` `Root\WinHookAudio` `pnputil`/`testsigning`, no `firewall` `netsh advfirewall firewall add rule name="WinHookAudio" dir=in action=allow protocol=UDP localport=6980-6981`, no `EV Cert`/`Attestation` + `bcdedit` `testsigning`. No `WHAA` `Vorbis` `libvorbis`/`r8brain` full in this spec (stub as `PCM` fallback).

## Solution
From the user's perspective: `Installer` `5 CLSIDs` `WinHookAudio Master` + `Bridge1..4` `HKLM\SOFTWARE\ASIO` via `WinHookAudio.reg` `CLSID_Master → Master DLL (512)` + `CLSID_B1..B4 → Bridge DLL (subset BRIDGE1..4, 4 clients)` + `Inno Setup` `WinHookAudio.iss` `6.x` `iscc` with `[Setup]` `AppName` `DefaultDirName` `{pf}\WinHookAudio` + `[Files]` `WinHookAudioMasterASIO64.dll` + `WinHookAudioBridgeASIO64.dll` + `WinHookAudio.sys` + `WinHookAudio.inf/.cat` to `{app}\driver` + `[Registry]` `Root: HKLM; Subkey: "SOFTWARE\ASIO\WinHookAudio Master/Bridge1..4"; ValueType: string; ValueName: "CLSID"; ValueData: "{CLSID_Master/B1..B4}"` + `[Run]` `pnputil /add-driver "{app}\driver\WinHookAudio.inf" /install` + `bcdedit /set testsigning on` for offline `test` cert + `[Run]` `netsh advfirewall firewall add rule name="WinHookAudio" dir=in action=allow protocol=UDP localport=6980-6981` with `ADMIN` check, `WinHookAudio.reg` `5` entries for offline `reg` syntax `ctest` without `ADMIN`, `WinHookAudio.inf` `Root\WinHookAudio` + `cat` placeholder for offline `inf` syntax, `EV Cert` + `Microsoft Attestation` for `Win11` normal mode deferred to `20` with `ADMIN=True` + `Bitwig` runtime gate. First slice is `reg`/`iss`/`inf` syntax offline (`stream_verified:false`) without `iscc`/`pnputil`/`netsh` run.

Seam: `WinHookAudio.reg` (`5` `CLSID` `HKLM\SOFTWARE\ASIO`) + `WinHookAudio.iss` (`Inno` `[Setup]`/`[Files]`/`[Registry]`/`[Run]` `pnputil` + `netsh`) + `WinHookAudio.inf/.cat` (`Root\WinHookAudio` `WDK` `PortCls` `WaveRT` `8× Stereo` `64KB` `RingBuffer`) + `wha_common` (`WHASlotTable` `virtualCables` `8`/`64` + `WHASharedMemory` `kSlotsJsonPath`) + `MasterHolder` (`doTick` `Virtual` `DeviceIoControl` already stubbed) + `WHAControlPanelUI.cpp` (`GENERAL` `Virtual Cables: [8 v]` already done). Offline gate: `reg`/`iss`/`inf` syntax `ctest` without `ADMIN`/`iscc`/`WDK`/`sys` install, `stream_verified:false` without `ADMIN`/`WDK`.

## User Stories
1. As a user, I want `WinHookAudio.reg` `5` entries `HKLM\SOFTWARE\ASIO\WinHookAudio Master` `CLSID_Master → Master DLL (512)` + `Bridge1..4` `CLSID_B1..B4 → Bridge DLL (subset BRIDGE1..4, 4 clients)`, so that `Bitwig` `Preferences → Audio → ASIO` shows `WinHookAudio Master` + `Bridge1..4`.
2. As a user, I want `Inno Setup` `WinHookAudio.iss` `6.x` `iscc` with `[Setup]` `AppName` `DefaultDirName` `{pf}\WinHookAudio` + `[Files]` `WinHookAudioMasterASIO64.dll` + `WinHookAudioBridgeASIO64.dll` + `WinHookAudio.sys` + `WinHookAudio.inf/.cat` to `{app}\driver`, so that `iscc` builds `WinHookAudio-Setup.exe`.
3. As a user, I want `Inno` `[Registry]` `Root: HKLM; Subkey: "SOFTWARE\ASIO\WinHookAudio Master/Bridge1..4"; ValueType: string; ValueName: "CLSID"; ValueData: "{CLSID_Master/B1..B4}"`, so that `HKLM\SOFTWARE\ASIO` `5 CLSIDs` are registered on install.
4. As a user, I want `Inno` `[Run]` `pnputil /add-driver "{app}\driver\WinHookAudio.inf" /install` + `bcdedit /set testsigning on` for offline `test` cert, so that `WinHookAudio.sys` `8× Stereo` `WDK` `PortCls` `WaveRT` `Root\WinHookAudio` is installed with `testsigning`.
5. As a user, I want `Inno` `[Run]` `netsh advfirewall firewall add rule name="WinHookAudio" dir=in action=allow protocol=UDP localport=6980-6981` with `ADMIN` check, so that `WHAA` `UDP 6980`/`6981` `PCM`/`Vorbis` is allowed.
6. As a user, I want `WinHookAudio.inf` `Root\WinHookAudio` `WDK` `PortCls` `WaveRT` `8× Stereo` `64KB` `RingBuffer` + `cat` placeholder for offline `inf` syntax, so that `inf` `Root\WinHookAudio` is verifiable without `WDK` `22621`.
7. As a tester, I want offline `ctest` green without `ADMIN`/`iscc`/`WDK`/`sys` install, `stream_verified:false`, `reg`/`iss`/`inf` syntax `ctest` without `ADMIN`/`iscc`/`WDK`, `iscc` + `pnputil` + `netsh` + `EV Cert` follow as `20` with `ADMIN=True`.
8. As a developer, I want `EV Cert` + `Microsoft Attestation` for `Win11` normal mode deferred to `20` with `ADMIN=True` + `Bitwig` runtime gate, so that `testsigning` is for offline `test` cert only.
